# ADR 0001 — Use a local-first fictional prototype

## Status

Accepted for this fictional example.

## Context

The primary uncertainty is whether the support review workflow is useful. Live
carrier integration would introduce credentials, external reliability and data
privacy before that workflow is validated.

## Decision

Use fictional local fixtures and a narrow delay-evaluation interface.

## Consequences

- The first slice can validate product behavior without external accounts.
- Integration reliability remains unproven and explicitly out of scope.
- A future carrier boundary requires a separate ADR and privacy/security review.
