# Pre-Delivery Checklist

- [ ] Re-read the slice objective.
- [ ] Confirm actual behavior matches intended behavior.
- [ ] Run focused validation.
- [ ] Run broader validation proportional to blast radius.
- [ ] Run `python tools/context_check.py`.
- [ ] Run `python tools/prepare_delivery.py`.
- [ ] Inspect `git status --short`.
- [ ] Remove transient debug/failure artifacts.
- [ ] Update canonical docs/contracts if behavior changed.
- [ ] Record validation evidence.
- [ ] Record intentional non-goals.
- [ ] Record residual risks/follow-ups.
