# Case Studies

These cases show how agentic guidance has been used in substantial delivery.
They are evidence libraries, not product templates or claims that one stack fits
every project.

All public names and scenarios are fictionalized. A case may combine verified
private evidence, owner-reported outcomes and synthetic explanation, with each
class labeled explicitly. No case provides a mapping back to its private source.

## Cases

- [Project Relay](project-relay/README.md): a mobile and API platform case that
  demonstrates cross-layer delivery, contracts, tests, visual regression,
  deployment and physical-device validation.
- [Project Aurora](project-aurora/README.md): a commercial website case that
  demonstrates product discovery, visual direction, content governance,
  production publication, search indexing and operational handoff.

## How to use them

Read a case only when its challenges resemble the current project. Extract the
questions, gates and validation strategy; do not copy its architecture or stack
without project-specific evidence and human approval.

Maintainers should follow [Learning From Real Projects](../docs/guides/REAL_PROJECT_LEARNING.md)
and start new cases from [the case-study template](../docs/templates/CASE_STUDY.md).
