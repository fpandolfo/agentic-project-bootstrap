# Agent-First Bootstrap

1. Read `START_HERE.md`.
2. Confirm `NEW_PROJECT`, `ADOPT_PROJECT` or `EVOLVE_PROJECT`.
3. Run `python3 tools/discover_project.py --target <target>` when available.
4. Read only the selected playbook and relevant capabilities.
5. Before writes, separate facts, inferences, unknowns and proposals.
6. Ask the human for missing intent and material decisions.
7. Generate only approved artifacts that have a clear durable owner.

The skill is an adapter. `START_HERE.md` and canonical repository files own the workflow.
