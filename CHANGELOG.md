# Changelog

All notable changes are documented here.

## Unreleased

### Added

- explicit temporal-decomposition and conjoined-module guardrails that organize
  boundaries around owned knowledge rather than execution order.

## 0.2.0-alpha.3 — 2026-08-18

### Added

- sanitized real-project case-study library with fictional public identities;
- agentic delivery lifecycle and proportional validation ladder;
- reusable generated-context, anti-drift, CI and delivery-gate guidance;
- explicit software-design philosophy and checklist inspired by John Ousterhout;
- portable obvious-system advisory with strict mode and unit tests;
- portable software-design-review skill routed to the canonical philosophy;
- tooling catalog separating available, guidance, candidate and local-only assets;
- private-to-public learning, evidence classification and privacy gates;
- reusable case-study and quality-strategy templates.
- isolated wheel and source-distribution consumer smoke tooling and CI artifact
  build coverage.
- release artifact checksum generation and text-only pack asset enforcement.

### Changed

- routed the capability catalog, project index and public READMEs to real-world
  delivery evidence without making case architecture a default.
- made the software-design philosophy discoverable from onboarding, playbooks,
  generated-project instructions and both sanitized cases.
- documented alpha ownership, upgrade and release-candidate boundaries.
- moved release artifact upload to the Node 24-based GitHub Action runtime.

### Known limitations

- upgrade and rollback are not automatic;
- supply-chain attestations and SBOM generation remain release follow-ups;
- the public case library still needs an internal-tool case and reviewed media;
- stack-specific executable recipes remain candidates rather than core promises.

## 0.2.0-alpha.2 — 2026-08-17

### Added

- universal `START_HERE.md` entry point for any capable coding agent;
- capability catalog, copy/paste prompts and new/adopt/evolve playbooks;
- content-free, read-only structural discovery in JSON or Markdown;
- explicit guidance for contexts, Mermaid diagrams, ADRs and human gates;
- synchronized agent-first guidance inside the distributable core pack;
- synthetic end-to-end example and discovery safety tests.

### Changed

- made `READ -> DISCOVER -> ASK -> PROPOSE -> APPROVE -> GENERATE -> OPERATE`
  the primary product experience;
- repositioned manifest/plan/apply/verify as optional deterministic plumbing;
- clarified that agent proposals are guidance, not final product decisions.

## 0.2.0-alpha.1 — 2026-08-17

### Added

- player-agnostic Python CLI;
- manifest schema and safe existing-repository adoption;
- built-in pack catalog with dependency resolution;
- fingerprinted plan/apply contract;
- managed state and verification;
- conflict, tamper, target-change and symlink guards;
- core, generic-agent, GitHub, Codex and Kiro packs;
- end-to-end test suite and least-privilege GitHub Actions;
- public license, security and contribution baseline.

### Changed

- evolved the local `v0.1.0` ZIP from a static starter into an executable public alpha;
- made Kiro and Codex optional adapters rather than core requirements.
